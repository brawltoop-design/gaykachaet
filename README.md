# GAYкачает

Быстрый веб-сервис: вставь ссылку → скачай видео в идеальнейшем качестве.
Тонкая обёртка над [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) + `ffmpeg`, вдохновлённая
[tuitube](https://github.com/remorses/tuitube), но в браузере и в один клик.

## Что умеет

- Вставляешь ссылку — сразу качается лучшее видео + лучший звук, склеенные в один файл.
- Живой прогресс (скорость, ETA, размер) через Server-Sent Events.
- Режим «Только звук (MP3)».
- Выбор качества: «Максимум» (до 8K) или «1080p H.264» — играет везде, включая QuickTime.
- 🎬 «H.264 для QuickTime/Premiere» (вкл. по умолчанию): если максимум качества доступен
  только в VP9/AV1 (обычно 4K+), файл после скачивания автоматически перекодируется
  в H.264 — на macOS аппаратно (VideoToolbox), в контейнере — через libx264.
  Разрешение сохраняется: 4K остаётся 4K, но открывается везде.
- ✂️ Обрезка: укажи начало и длительность (например, 15 сек) — скачается **только этот кусок**,
  без выкачивания всего ролика. Обрезанные клипы всегда выходят в H.264 (точная резка
  идёт через перекодирование), так что даже 4K-кусок играет в QuickTime.
- Работает с YouTube, TikTok, Instagram, X, Twitch, VK, Reddit и сотнями других сайтов
  (всё, что поддерживает `yt-dlp`).
- Ноль зависимостей npm — только стандартная библиотека Node.

## Требования

- **Node.js** ≥ 18
- **yt-dlp** в `PATH`
- **ffmpeg** в `PATH` (нужен для склейки видео+звука и для MP3)

```bash
brew install yt-dlp ffmpeg   # macOS
```

## Запуск

```bash
npm start
# → http://localhost:8787
```

Переменные окружения:

| Переменная      | По умолчанию | Назначение                                  |
| --------------- | ------------ | ------------------------------------------- |
| `PORT`          | `8787`       | Порт сервера                                |
| `HOST`          | `0.0.0.0`    | Интерфейс                                   |
| `MERGE_FORMAT`  | `mp4`        | Контейнер склейки (`mp4`, `mkv`, `webm`)    |

## Как это работает

1. Браузер открывает `EventSource` на `/api/download?url=…`.
2. Сервер запускает `yt-dlp -f "bv*+ba/b" --merge-output-format mp4` во временную папку,
   парсит прогресс и шлёт его в браузер.
3. По готовности отдаётся одноразовый токен; браузер сам стартует скачивание
   с `/api/file/<token>`.
4. Файл живёт 15 минут, затем временная папка удаляется. Отдал файл — удалили сразу.

## Деплой

Сервису нужен **долгоживущий процесс** с `ffmpeg` и `yt-dlp` на борту, поэтому
serverless (Vercel/Netlify/Cloudflare) **не подходит** — только контейнер-хостинг
или VPS. В репозитории есть готовый `Dockerfile`.

### Render (проще всего, есть бесплатный тариф)

1. Render Dashboard → **New → Blueprint**.
2. Выбрать этот репозиторий — Render подхватит `render.yaml` и `Dockerfile`.
3. **Apply** → через пару минут получишь `https://gaykachaet.onrender.com`.

Бесплатный инстанс засыпает после ~15 мин простоя и просыпается за ~30 сек на первом запросе.

### Fly.io

```bash
flyctl launch --copy-config --now   # первый раз
flyctl deploy                       # обновления
```

### Свой VPS

```bash
docker build -t gaykachaet .
docker run -d --restart=unless-stopped -p 80:8787 gaykachaet
```

### ⚠️ Про YouTube с облачных IP

YouTube часто блокирует IP дата-центров: `Sign in to confirm you're not a bot`.
Другие сайты (TikTok, Instagram, X, VK…) обычно качаются нормально. Чтобы YouTube
стабильно работал из облака, нужны cookies:

1. Экспортируй cookies из браузера (расширение «Get cookies.txt»).
2. Положи файл рядом и добавь в `server.js` в аргументы `yt-dlp`:
   `'--cookies', '/path/cookies.txt'`.

Самый надёжный вариант для YouTube — крутить сервис **дома** (жилой IP) и открыть
наружу через Cloudflare Tunnel / Tailscale.
